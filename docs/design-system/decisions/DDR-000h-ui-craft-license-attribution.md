# DDR-000h: Upstream Apache-2.0 License & Attribution (Settlement A8)

- **Status:** Ratified
- **Date:** 2026-10-08
- **Decider:** Owner (via D Track Brief §5 Settlement A8)
- **Phase / Step:** D0.S3
- **Affects:** Open Source Licensing, Compliance

---

## 1. Context
`ui-craft` absorbs parts of `impeccable` (Apache-2.0 by Paul Bakaus). In a public repository, all third-party license notices and attributions must be preserved and committed alongside the skill.

## 2. Decision
The upstream Apache-2.0 license and NOTICE text are maintained in `ui-craft/` and documented in all derivative design system tooling to ensure strict license compliance.
