# Persona Ranking & Tie-Break Order

This ranking defines the strict hierarchy used during `/ui-craft critique` and `/ui-craft consensus` reviews whenever visual trade-offs, screen estate constraints, or design conflicts arise.

---

## The Ranking Order

1. **`graph-glancer` (Primacy 1 — The In-Flow Graph Glancer)**  
   *Justification:* The primary job of the adjacent graph is to give immediate, at-a-glance orientation beside the active chat. Nothing on screen may compromise pre-attentive node clarity, quiet peripheral composure, or truthful steering representation while a user is typing.

2. **`context-recoverer` (Primacy 2 — The Traceback Searcher)**  
   *Justification:* If clicking a requirement bead or outcome node fails to jump directly to the verbatim conversation turn, the graph fails its core spatial utility. Traceback integrity always outranks high-level exploratory aesthetics.

3. **`brain-navigator` (Primacy 3 — The Macro Explorer)**  
   *Justification:* While the 3D Symbiotic Cortex provides macro wonder and cross-project orientation, macro exploration is an episodic, reflective mode that must never impose performance lag or cognitive clutter on the focused chat graph workspace.

---

## Tie-Break Rules
- If visual effects compete with peripheral quietness or at-a-glance node clarity: **`graph-glancer` wins**.
- If spatial clustering aesthetics compete with clickable target precision or direct jump-to-chat traceability: **`context-recoverer` wins**.
- If macro 3D views compete with in-chat graph rendering budgets: **`graph-glancer` and `context-recoverer` win**.
